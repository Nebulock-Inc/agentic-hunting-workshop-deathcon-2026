# commands/

One file per `athf` command the workshop asks you to run. `.sh` for macOS/Linux, `.ps1` for Windows.
Run the file; don't retype the flags. Edit `<your-name>` and any `<…>` placeholder first.

`athf hunt new` numbers hunts itself. From a fresh `athf init` (which seeds H-0001–H-0003) the six workshop hunts land as H-0004 … H-0009, and that is how the labs refer to them. Got a different number? Use yours wherever the lab says H-000x.

Generated from `curriculum/*/LAB.md` by `staff/gen-attendee-files.py` — edit the lab, not these.
